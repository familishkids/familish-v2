# Familish English School for Kids — Proposal Website

A responsive, single-page website concept inspired by the cheerful, child-friendly feel of Japanese children's English schools.

## Run locally
Open `index.html` in a browser, or run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Notes
- This is a proposal concept, not a live official school website.
- Copy, programs, testimonials, contact details, and school information are placeholders and should be confirmed before publication.
- Photos are loaded from Unsplash source image URLs and require an internet connection.
